# Carnicería Chapala – proyecto escolar

Sitio web de demostración hecho con **HTML5, CSS3 y JavaScript** (sin frameworks, sin servidor y sin base de datos).
Proyecto escolar para la Feria de Informática 2026.

> **Importante:** los precios son **ilustrativos y están sujetos a confirmación**. El simulador de compras es una
> **simulación educativa: no vende, no cobra y no guarda datos**. El sitio no pide datos personales.

## Qué contiene
| Archivo / carpeta | Contenido |
|---|---|
| `index.html` | Inicio |
| `productos.html` | Tarjetas, tabla de precios y simulador de compras |
| `juegos.html` | Juego ChapalaWare (microjuegos y jefe) |
| `css/estilos.css` | Estilos |
| `js/app.js` | Catálogo de productos y simulador |
| `js/juegos.js` | Juego ChapalaWare |
| `img/` | Logos, fotos de productos y `img/texturas/` (imágenes del juego) |
| `sfx/chomp.m4a` | Música de fondo del juego (se puede silenciar) |
| `docs/` | Guía para defender el código e informe de auditoría |

## Probar en la computadora
Abrir `index.html` con doble clic (no hace falta instalar nada).

## Publicar en GitHub Pages
1. Crear un repositorio en GitHub y subir **el contenido de esta carpeta** (que `index.html` quede en la raíz del repositorio).
2. En el repositorio: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, rama `main`, carpeta `/ (root)`.
3. Esperar un par de minutos: el sitio queda en `https://<usuario>.github.io/<repositorio>/`.
4. Probar en la dirección publicada las tres páginas y el juego (también desde un celular).

Todas las rutas del sitio son **relativas** y funcionan en una subcarpeta como la de GitHub Pages. En GitHub Pages las
mayúsculas y minúsculas importan: no renombrar archivos sin actualizar las rutas.

## Antes de publicar (pendientes del grupo)
Ver `docs/INFORME_AUDITORIA.md`, sección «Condiciones para publicar»: licencias y autorizaciones de imágenes, logos y sonido,
precios y datos de contacto.
